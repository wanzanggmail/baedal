# 라이더 매뉴얼

## 1. 처음 이용하기

### 로그인

1. 대리점에서 받은 로그인 아이디와 비밀번호를 입력합니다.
2. 아이디를 모르면 등록된 휴대전화 번호로 로그인을 시도할 수 있습니다.
3. 로그인 유지가 필요하면 **로그인 상태 유지**를 선택합니다.
4. 초기 비밀번호 사용자에게 비밀번호 변경 화면이 나오면 안내에 따라 새 비밀번호를 설정합니다.

로그인은 10분 동안 5회 실패하면 잠시 제한됩니다. 반복 입력하지 말고 제한 시간이 지난 후 다시 시도하십시오.

### 초기 비밀번호 변경

1. 현재 비밀번호를 입력합니다.
2. 4자 이상의 새 비밀번호를 입력합니다.
3. 같은 값을 비밀번호 확인에 입력합니다.
4. 초기 비밀번호와 다른 값을 사용합니다.

비밀번호 변경 전에는 홈이나 정산 화면을 사용할 수 없습니다.

### 로그인할 수 없는 상태

- **일시 정지**: 대리점에 상태 확인 요청
- **탈퇴 처리 중**: 처리 완료 여부를 대리점에 문의
- **계약 종료**: 기존 계정으로 로그인 불가

## 2. 홈 화면

홈에서 다음 정보를 한 번에 확인합니다.

- 출금 가능 금액
- 이번 달 정산 금액
- 등록 계좌 상태
- 처리 중인 출금
- 최근 정산과 프로모션
- 미수금
- 공지와 배너

출금 가능 금액은 지갑 잔액 전체와 다를 수 있습니다. 보증금, 출금수수료, 출금 가능한 정산 기간이 반영됩니다.

## 3. 정산 확인

### 정산 수수료 내역

실제 정산 금액을 확인할 때 우선 사용하는 화면입니다.

1. 하단 **정산** 탭을 누릅니다.
2. 조회 시작일과 종료일을 선택합니다.
3. 총 정산액, 공제, 순지급액을 확인합니다.
4. 일별 정산 카드를 눌러 상세 항목을 확인합니다.

상세에서는 플랫폼 정산액, 원천세, 보험료, 대행 수수료, 미수금 등 적용 항목을 확인할 수 있습니다.

### 정산 달력

1. 메뉴에서 **정산 달력**을 선택합니다.
2. 금액이 표시된 날짜를 선택합니다.
3. 해당 날짜의 정산과 주문 상세를 확인합니다.

관리자가 파일을 업로드만 하고 **정산 반영**을 하지 않은 자료는 달력과 정산 내역에 표시되지 않습니다.

### 정산 목록과 정산 상세(샘플)

현재 `정산 목록`과 `정산 상세(샘플)`은 목업 화면입니다. 표시 금액과 요기요 항목은 실제 지급·정산 판단에 사용하지 마십시오. 실제 데이터는 **정산 수수료 내역**과 **정산 달력**에서 확인합니다.

## 4. 프로모션

하단 정산 탭 또는 메뉴에서 **프로모션**을 선택합니다.

- 지급일
- 지급명
- 지급 금액
- 처리 상태

를 확인할 수 있습니다. 프로모션은 일반 정산과 별도로 지갑에 적립됩니다.

## 5. 출금 신청

### 신청 전 확인

- 라이더 상태가 활동 중이어야 합니다.
- 계좌가 등록되어 있어야 합니다.
- 출금 보류 상태가 아니어야 합니다.
- 처리 중인 출금 신청이 없어야 합니다.
- 보증금과 수수료를 제외한 출금 가능 금액이 있어야 합니다.

계좌 정보 화면은 조회 전용입니다. 등록 또는 변경이 필요하면 소속 대리점에 요청하십시오.

### 출금 신청 절차

1. 하단 **출금** 탭을 누릅니다.
2. 달력에서 마지막으로 출금할 정산일을 선택합니다.
3. 오래된 미출금 정산부터 선택한 날짜까지 계산된 내역을 확인합니다.
4. 사용 금액, 보증금, 정산수수료와 실지급액을 확인합니다.
5. **출금 신청**을 누릅니다.
6. 신청 완료 메시지를 확인합니다.

출금 신청 시점에는 지갑 잔액이 즉시 차감되지 않습니다. 관리자가 실제 이체 후 완료 처리하면 잔액이 차감됩니다.

### 출금 상태

- **신청 대기**: 관리자가 아직 처리하지 않음
- **처리 중**: 이체 파일 다운로드 등 지급 처리 중
- **처리 완료**: 은행 이체가 완료되고 지갑에서 차감됨
- **반려**: 신청 취소, 해당 정산은 다시 신청 가능

### 선정산 라이더

선정산 라이더는 원칙적으로 앱에서 직접 출금 신청하지 않고 대리점이 **일일정산 지급**으로 처리합니다. 앱에 출금 신청 기능이 보이더라도 소속 대리점의 운영 정책을 먼저 확인하십시오.

## 6. 출금 내역과 상세

1. 출금 화면에서 **신청 내역**으로 이동합니다.
2. 신청일, 기간, 금액과 상태를 확인합니다.
3. 항목을 선택하여 정산일별 금액, 공제와 출금수수료를 확인합니다.

처리 중인 신청이 있으면 새 신청을 할 수 없습니다. 완료 또는 반려될 때까지 기다리거나 대리점에 문의하십시오.

## 7. 내 정보

### 프로필

이름, 연락처, 소속 대리점, 정산 유형과 계정 상태를 확인합니다. 정보가 다르면 대리점에 수정을 요청합니다.

### 계좌 정보

등록 은행, 계좌번호, 예금주를 확인합니다. 보안을 위해 앱에서는 직접 수정하지 않습니다.

### 미수금

대여금, 리스, 선지급 원금과 상환 내역을 확인합니다. 미수금은 수수료가 아니며 정산 반영 과정에서 차감될 수 있습니다.

### 비밀번호 변경

현재 비밀번호와 새 비밀번호를 입력하여 변경합니다. 초기 비밀번호와 동일한 값은 사용할 수 없습니다.

## 8. 공지

하단 **내정보** 탭 또는 메뉴에서 공지 목록을 확인합니다. 소속 대리점, 상위 조직 또는 전체 대상으로 게시된 공지가 표시됩니다.

## 9. 자주 묻는 질문

### 출금 가능 금액이 지갑 잔액보다 적습니다

보증금, 출금수수료와 출금 가능한 정산 사이클을 반영한 금액이기 때문입니다. 최근 정산과 오래된 정산의 건당 수수료가 다를 수 있습니다.

### 출금 신청 후 잔액이 그대로입니다

정상입니다. 신청 대기와 처리 중에는 금액을 예약하고, 관리자가 완료 처리할 때 지갑 잔액을 차감합니다.

### 출금 가능한 정산 내역이 없다고 나옵니다

- 관리자가 아직 정산 반영을 하지 않음
- 이미 출금한 기간임
- 선택한 종료일까지 출금 가능한 정산이 없음
- 보증금과 수수료를 제외하면 실지급액이 없음

선택 날짜를 확인한 후 계속 발생하면 대리점에 문의하십시오.

### 계좌를 등록하거나 변경하고 싶습니다

앱에서는 계좌를 조회만 할 수 있습니다. 소속 대리점 관리자에게 요청하십시오.

### 출금 보류라고 나옵니다

관리자가 라이더 상세에서 출금 보류를 설정한 상태입니다. 대리점에 해제 사유와 절차를 문의하십시오.

### 로그인이 계속 실패합니다

- 아이디 대신 등록된 휴대전화 번호로 시도
- 비밀번호 대소문자와 숫자 확인
- 5회 실패했다면 10분 후 재시도
- 계정이 정지·탈퇴·종료 상태인지 대리점에 확인

### 정산이 보이지 않습니다

관리자에게 업로드 여부가 아니라 **정산 반영 완료 여부**와 라이더 매칭 여부를 확인해 달라고 요청하십시오.

### 정산 목록과 수수료 내역 금액이 다릅니다

정산 목록과 샘플 상세는 현재 목업입니다. 실제 금액은 정산 수수료 내역과 정산 달력을 기준으로 확인하십시오.

### 반려된 출금을 다시 신청할 수 있습니까

반려되면 연결된 정산의 점유가 해제되므로 조건을 충족하면 다시 신청할 수 있습니다.

## 10. 문의할 때 준비할 정보

문제를 빠르게 확인하려면 다음 정보를 대리점에 전달합니다.

- 로그인 아이디 또는 휴대전화 끝 4자리
- 문제가 발생한 화면
- 정산일 또는 출금 신청일
- 표시된 오류 문구
- 출금 신청 번호나 정산 일자

계좌 전체 번호, 비밀번호, 인증정보는 메신저나 화면 캡처로 전달하지 마십시오.
